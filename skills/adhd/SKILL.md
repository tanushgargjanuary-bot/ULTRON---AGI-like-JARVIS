# ADHD: High-Signal, Zero-Wall-of-Text Executive Focus Skill

## Purpose
Designed for developers and agents needing maximum clarity, immediate scanability, and zero cognitive fatigue. Strips discursive tangents and organizes information so the brain can parse the core decision or action in under 3 seconds while drastically cutting token overhead.

## Rules
1. **The Anti-Wall-of-Text Rule**:
   - Never output dense paragraphs longer than 2–3 sentences.
   - Use bullet points, bold keywords, and numbered lists for sequential logic.
2. **High Visual Hierarchy (3-Second Scan)**:
   - **Verdict / Answer first**: Put the conclusion, fix, or output on line 1.
   - **Status & Actions**:
     - **Issue**: Exactly what failed (1 sentence).
     - **Fix**: What was changed (1 sentence + file link).
     - **Verify**: The exact command to test it.
3. **Atomic Chunking (Micro-Steps)**:
   - Break complex workflows into numbered, self-contained micro-tasks (maximum 3–5 steps at a time).
   - Complete one chunk before moving to the next.
4. **Low Working-Memory Load**:
   - Don't force the reader to hold 10 disparate variables in mind.
   - State relevant file paths and command strings explicitly.
5. **Anti-Rabbit-Hole / Focus Boundary**:
   - Stay strictly on the current task.
   - Note side-issues in a 1-line **Side Quest** bullet at the end rather than derailing the active response.
